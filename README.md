# 影片紀錄

記錄影片的片名、演員和性質，用一個搜尋框就能找到。

## 功能

### 記錄影片
- 每部影片有**片名**（必填）、**演員**（可以好幾位）、**性質**（可以好幾種）。
- 按「新增影片」（Ctrl+N）填寫；連按兩下清單上的影片，或選取後按 Enter，可以修改。
- 演員：打名字按 Enter 加入。打字時會列出現有的演員，用 ↑↓ 選或直接點。頓號、逗號可以一次打好幾位。
- 性質：點一下選取、再點一下取消。打字按 Enter：現有的會選取，沒有的會新增。
- 性質分**大項**和**小項**（例如大項「動作」底下有「槍戰」、「追車」）。影片可以標大項，也可以標小項。
  打 `動作/槍戰` 按 Enter，會把「槍戰」加在「動作」底下（「動作」還沒有就一起新增）。
- 全程可以只用鍵盤：片名 Enter → 演員 Enter … → 性質 Enter … → 空白時再按 Enter 就儲存。
- 「儲存並新增下一部」（Ctrl+Enter）適合一次記很多部。
- 片名已經有了會先詢問。
- 選取後按 Delete 刪除，按住 Ctrl 或 Shift 可以選好幾部。

### 搜尋
- 打字就即時篩選，片名、演員、性質都會找。Ctrl+F 回到搜尋框，Esc 清除，Enter 或 ↓ 跳到結果。
- 空格分開可以打好幾個關鍵字，要全部符合（例如 `王小明 動作`）。
- 不分全形半形、大小寫，也不計較名字中間的空格（`ＡＢＣ` 等於 `abc`，`王 小明` 等於 `王小明`）。
- 左邊點性質或演員就能篩選，可以選好幾個（要全部符合）。旁邊的數字是目前結果裡有幾部。
- 選大項（或搜尋大項的名字）時，標了它底下小項的影片也會找到；大項旁邊的數字也包含小項的影片。
- 點表格標題可以排序，預設最新新增的在最上面。

### 管理性質與演員
- 新增、改名、刪除性質；新增時可以選放在哪個大項底下，之後也可以用「所屬大項」換位置。
- 只有兩層：小項底下不能再分。大項改名時小項會跟著；刪除大項時，底下的小項會變成大項，不會被刪除。
- 1.0 版的資料直接沿用，原本的性質全部是大項。
- 演員打錯字或同一個人有兩種寫法時可以改名；改成已經有的名字就是合併。
- 刪除性質或演員，只會從影片上移除這個名字，影片本身不會被刪除。

資料存在 `%AppData%\Video\data.json`，是一般的 JSON 檔，可以直接備份。解除安裝不會刪除資料。
資料只存在自己的電腦，不會上傳。

## 安裝

到 [Releases](https://github.com/asdZzz-coder/video/releases) 下載 `Video-Setup.msi`，執行就會安裝並開啟。

- 只裝給目前使用者，不需要系統管理員權限，電腦也不用另外安裝 .NET。
- 這個 App 不放進「APP 啟動器」。
- 程式開啟時會檢查新版，也可以按右下角的「檢查更新」。
- 要移除時到「設定 → 應用程式」解除安裝。

## 開發

需要 .NET 10 SDK。

```bash
dotnet build video.slnx
dotnet test video.Tests/Video.Tests.csproj
dotnet run --project video
```

測試時可以設定環境變數 `VIDEO_DATA_DIR` 改用別的資料夾，就不會動到正式資料，也可以和正式版同時開。

自己打包安裝檔（需要網路下載 WiX）：

```bash
dotnet build installer/Video.Installer.wixproj -c Release -p:AppVersion=1.0.0
```

產生的檔案在 `installer/bin/x64/Release/Video-Setup.msi`。

## 發佈新版本

推送 `v*` 標籤後，GitHub Actions 會跑自動測試、打包安裝檔，並上傳到 GitHub Releases。

```bash
git tag v1.0.0
git push origin v1.0.0
```
